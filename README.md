# ONDA PERFUME STUDIO (온다 향방)

포항 영일대 해변의 파도와 솔숲, 윤슬의 순간을 향으로 조향하는 프리미엄 비스포크 향수 스튜디오 '온다(ONDA)' 공식 웹사이트입니다.

## ✨ 주요 기능
- **브랜드 스토리 & 비주얼 슬라이더**: 포항 영일대 바다와 아틀리에 감성을 담은 실사 비주얼 슬라이드
- **시그니처 향수 컬렉션**: 윤슬(YUNSEUL), 온다(ONDA), 웜샌드 & 파인브리즈, 홈 프래그런스
- **원데이 클래스 & 조향 프로그램 안내**: 시그니처 조향 클래스, 모바일 간편 예약 모달 연동
- **고객 리뷰 & 평점 시스템**: 카테고리 필터링 및 실시간 리뷰 작성/저장 기능 (로컬 스토리지 연동)
- **관리자(Admin) 페이지**: 실시간 예약 접수 현황, 리뷰 승인/관리, 매출/통계 대시보드
- **반응형 웹 디자인**: 모바일, 태블릿, 데스크톱 최적화 레이아웃

## 🛠️ 기술 스택
- HTML5 / CSS3 (커스텀 디자인 시스템 & 부드러운 애니메이션)
- Vanilla JavaScript (ES6+)
- 호스팅 & 배포: GitHub + Vercel
